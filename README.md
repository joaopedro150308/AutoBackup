# AutoBackup
Um aplicativo para fazer backups de arquivos

### Bloco de leitura

    - Consegue os caminhos dos arquivos a partir do usuário

### Bloco de definição de Arquivo(s) e Backup(s)

    - Tem como base os caminhos dos arquivos para declar cada elemento de tipo Arquivo
    - Backup é um elemento que possúi um conjunto de arquivos, local de destino, nome da pasta de destino
